      Sustento y límites

      Supuestos
      • Los datos de animales, DT-e y establecimientos son DATO SIMULADO.
      • SUPUESTO: no hay una API pública de SENASA para terceros; el ingreso real sería por archivos que descarga el productor.
      • SUPUESTO: el productor paga primero (a validar contra el frigorífico/exportador).
      Límites del prototipo
      • No evalúa evidencia ambiental (deforestación, EUDR): figura como "no evaluada".
      • No hay firma digital ni verificador externo: el nivel "verificado" no se puede alcanzar acá.
      • No consulta SENASA ni valida contra registros oficiales.
      • El sello SHA-256 prueba integridad, no veracidad. No usa blockchain.
      Fuentes
      • SENASA, identificación electrónica
      • Comisión Europea, EUDR
      • Global Forest Watch
